# CyberSecure — site institucional e portal de conteúdo

Projeto estático do site CyberSecure.

## Arquivos
- `index.html`: HTML principal do site.
- `assets/css/style.css`: estilos da interface.
- `assets/js/main.js`: funcionalidades interativas.
- `cybersecure-demo-standalone.html`: versão autônoma original para referência.

## Desenvolvimento
Abra `index.html` no navegador ou utilize um servidor HTTP estático. Para editar o projeto, modifique os arquivos em `assets/`, mantendo a página HTML como estrutura.

## Publicação
A Hostinger está integrada ao repositório. Trabalhe na branch de desenvolvimento e revise as alterações antes de integrá-las à `main` (branch usada para publicação).

## Validação antes de publicar
- Conferir layout em dispositivos móveis e desktop.
- Validar menu, pesquisa, filtros e links internos.
- Verificar carregamento do CSS e JavaScript.
- Revisar acessibilidade, SEO e performance.

## Evolução
O HTML ainda contém imagens incorporadas em base64. Elas poderão ser externalizadas em etapa futura para facilitar manutenção e cache.
